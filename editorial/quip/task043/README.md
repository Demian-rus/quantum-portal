# TASK043 — журнал пополнения

627 исходных предложений, после индивидуального прохода 248 принятых решений.
`decisions.tsv` задаёт конкретные уровни по каждой записи: порядок колонок
рейтинга talk / mime / draw / yesno / blitz, 0 — недопустимо, 1/2/3 — easy/medium/hard.
Оценки не выводятся из длины, категории или соседней строки.
Все новые записи — лексические задания/персонажи: sing и approx явно недопустимы;
Secret наследует фактический метод. Полный quip@1 review-table будет собран
из этих явных решений с точными fingerprints исходных записей.

`candidates.json` сохраняет все отказы, исходное и исправленное написание,
нормализованные совпадения и подсказки для смысловой проверки. Нормализация
учитывает Unicode NFKC, Ё/Е, регистр, пунктуацию, пробелы и дефисы. Дополнительный
авторский проход использует OpenCorpora через pymorphy3 (2.0.6) и rapidfuzz (3.14.6);
результат морфологии — подозрение, а не автоматический приговор. Например,
ГОФРЕ / ГОФРА отложено по многозначности, а не записано как доказанный дубль.

Сверены все 7 697 ID действующей редакции, все исторические исходные строки и
исправление idiom-000083 из TASK042. Технические точные совпадения и ручные
смысловые решения доступны по отдельности. Новая карточка не становится песенной
темой или вопросом оценки числа лишь из-за своего текста. Эти два режима в этом
пополнении сохраняют существующие проверенные задания.

Формулировки и аргументация составлены самостоятельно. Полные тексты песен,
чужие словарные статьи, изображения персонажей и чужие описания не копируются.
Редкие написания и спорные имена уточняются по словарям и первичным/официальным
страницам; конкретные исправления с источниками находятся в `text-edits.json`.
Статус reviewed означает индивидуальную смысловую работу модели;
владелец ещё не проводил ручную приёмку.
