# Quantum Portal

Репозиторий с веб-играми и экспериментальными игровыми интерфейсами. На главной странице размещён портал; отдельное приложение **КВИП** развивается в `party-game/`.

**Портал:** https://demian-rus.github.io/quantum-portal/  
**КВИП:** https://demian-rus.github.io/quantum-portal/party-game/

## Структура

- `index.html`, `styles.css`, `core.js` и соседние файлы — главная страница портала и связанные веб-игры.
- `party-game/` — самостоятельная PWA КВИП с игровым кодом, контентом, тестами и документацией.
- `.github/workflows/` — автоматические проверки и публикация.

**Важно:** `main` — опубликованный исходный код. Draft PR не равнозначен релизу; не сливайте контентные ветки с устаревшими функциональными ветками без сверки зависимостей.
