# КВИП — тема «Животные» (@2)

Первый активный релиз темы (историческая animals@1 остаётся неактивной заглушкой):, подготовленная независимо от TASK 010 (баланс). Она появится в меню «Новая игра → Тематическая» после слияния PR. **Общий стандартный каталог general@6 не изменён.** Старые тематические версии и сохранённые партии не затрагиваются.

## Наполнение

| Тип | Доступно в теме |
| --- | ---: |
| Слова | 232 |
| Словосочетания | 56 |
| Персонажи для Данеток | 66 |
| Числовые вопросы «Примерно» | 103 |
| **Всего уникальных заданий** | **457** |

Добавлено **216 новых редакционных карточек**: 126 слов (46 easy / 39 medium / 41 hard), 56 словосочетаний (18 / 20 / 18), 34 персонажа (14 / 12 / 8). Остальные 241 уже существовали в каталоге: 138 различных слов/персонажей и 103 проверенных ранее числовых вопроса с тегом animals.

Карточки других тем не копируются: используются исходные ID. Для исторических неразмеченных карточек применён **явный перечень ID**, а не догадка по тексту. В частности, известные звери из старого общего словаря и герои мультфильмов входят в тему без изменения их исторических метаданных. Пересечение с общим набором предусмотрено.

## Режимы

Слова / Жесты / Нарисуй используют 288 слов и словосочетаний; Блиц — короткие easy-слова; Данетки — 66 персонажей; «Секретка» — подходящие способы с обязательным усложнением; «Примерно» — 103 числовых вопроса. «Напой» отсутствует: в тему не включены музыкальные карточки.

## Качество и проверка

- Все 216 новых текстов прошли точную нормализованную проверку против общего архива: пробелы, ё/е, регистр и знаки препинания.
- 56 кандидатов с уже существующими названиями не добавлялись повторно; проверенные нужные записи используются через прежние ID.
- Из кандидатов исключён «Дядюшка Скрудж», поскольку в старом каталоге уже есть тот же персонаж «Скрудж Макдак».
- Новых эмпирических числовых фактов нет: повторно используются 103 проверенных вопроса об животных из активного общего каталога.
- Существующие файлы-источники не редактировались. Новые записи в `content/cards/animals-v2.json`, новая версия набора — `content/packs/animals-v2.json`.
- Полная редакторская проверка смысловых аналогов остаётся человеческой задачей: близкие виды и уточняющие словосочетания могут быть содержательно разными карточками.
