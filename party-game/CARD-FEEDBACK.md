# UX и оценки — Issues #95 / #96

База: PR #94, `959017bf33c5bb8a8fd08ba047ad99c82682e32d`. Отдельная последовательная ветка; #94 не изменяется. PWA v80 — только кандидат.

## Экран

Карточка имеет фиксированную строку сетки во всех task/countdown/play. Нижняя строка учитывает реальные размеры действий вместо симметричных пустых долей. Результаты: 54–68 px в портрете, 48 px в landscape. Красная и зелёная оценки по 48 px (44 px в landscape) находятся слева и справа от таймера. Пауза Easy перенесена в шапку, на место скрытого во время play флажка. В Блице завершение занимает свободную центральную ячейку между результатами. Флажки task/judge/Примерно, тай-брейка и истории остаются.

Обычное усложнение не имеет внутренней прокрутки. Для исключительно длинного исторического текста доступна прокрутка всей верхней области с клавиатуры и касанием; карточка и действия остаются доступны. Длинная карточка использует адаптивную типографику и собственный безопасный overflow только при реальном переполнении. В landscape сохранена двухколоночная компоновка с зазором до шапки и результатов.

Два presentation-only alias применяются только при совпадении modifierVersion=2, ID и полного исходного снимка: `v2-other-hand` → «Рисуй неведущей рукой.», `v2-closed-mouth` → «Напевай с закрытым ртом, без слов.». Исходный текст остаётся в saved current.complication и title региона. Другой текст, V1 и запись без ID показываются буквально. Каталоги V1/V2, их критерии, веса и история не редактировались.

## Исключительное удержание таймера

`feedback-clock.js` сохраняет в current.feedbackHold `{version:1, phase, remainingMs, wasPaused}`. Это отдельное пользовательское действие, не изменение timerPolicyVersion. Обычная пауза Medium/Hard/Mixed остаётся запрещённой.

Перед показом жалобы остаток фиксируется и сохранение проверяется чтением. Play получает paused=true, deadline=null; countdown сохраняет именно оставшуюся долю секунды автостарта. Tick, ручные игровые действия и восстановление не могут завершить удержанный раунд. После перезапуска приложение предлагает Continue; тот же диалог открывается с сохранённым остатком. Ни профили, ни статистика, ни история не пересчитываются. Неизвестная/повреждённая версия hold защищает исходный RAW.

Save, Cancel, Back, Escape, фон и крестик используют один release. Новый deadline = время закрытия + сохранённый остаток; ранее приостановленная Easy остаётся на паузе. Истёкший до клика раунд не оживает. Ошибка записи удержания не открывает диалог; ошибка сохранения возобновления оставляет диалог открытым для повторной попытки. При неподтверждённом откате запись игры блокируется. Web Storage не даёт межвкладочного CAS; параллельное управление одной партией из нескольких вкладок не поддерживается.

## Журналы

Ядро TASK017 `card-reports.js` сохранено побайтово: ключ `kvip-card-reports:v1`, шесть причин, ID, validate/readback/rollback, лимит 500 и старый JSON экспорт. Поле комментария доступно для любой причины, предел 160 Unicode-символов прежний.

Одобрения: отдельный `kvip-card-approvals:v1`, `{version:1,items}`; каждая запись содержит только itemKey, TASK017 item, createdAt/updatedAt. Лимит 500, без автоматического удаления. Повторное одобрение не пишет повторную запись и не меняет игру, таймер или профиль. Строковый ключ тот же: cardId + pack id/version; legacy без ID использует прежний безопасный составной ключ. ID по совпавшему тексту не выдумываются.

Смена оценки требует явного подтверждения. Сначала проверяется запись замены, затем удаляется прежняя оценка. При ошибке обе исходные строки восстанавливаются с readback; старый рейтинг восстанавливается до удаления подтверждённой замены. Если откат нельзя подтвердить, дальнейшие записи блокируются, подтверждённая замена остаётся доступна для экспорта. Это best-effort транзакция Web Storage, не межвкладочная транзакционная база.

## Передача

Объединённый JSON: `{kind:'kvip-card-feedback',version:1,exportedAt,approvals:{version:1,items},reports:{version:1,items}}`. Профилей, имён команд, счёта и истории партий нет. Экспорт не очищает архивы.

Web Share проверяет именно `navigator.canShare({files})`; `navigator.share` вызывается в обработчике клика до первого await. Подтверждение показывается только после разрешения Promise, без утверждения о доставке получателю. Cancel и ошибка оставляют журналы. Всегда доступна отдельная «СКАЧАТЬ JSON»; старый экспорт замечаний сохранён. Токенов и GitHub POST нет. Контракт платформы: https://www.w3.org/TR/web-share/ .
