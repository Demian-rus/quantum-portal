## Редакторская проверка

Собраны и рассмотрены более 300 кандидатов на отдельные слова и 70 на словосочетания. Проверка нормализации (NFKC, ё→е, регистр, пробелы, пунктуация) против **6076 предыдущих текстовых карточек**, включая G27, не обнаружила точных повторов среди 50 отобранных. Ручная редактура оценивает и смысловые сходства; алгоритм не может гарантировать отсутствие всех тематических пересечений.

| Отклонённый кандидат | Причина |
| --- | --- |
| ИСКРА | «ЭЛЕКТРИЧЕСКАЯ ИСКРА» — уже использован основной образ |
| МЕЛЬНИК | «МЕЛЬНИЦА» — близкий центральный образ в игровой ассоциации |
| ПЕРЕЙТИ РУБИКОН | Уже присутствует дословно |
| РЕСНИЦА | Дословно присутствует |
| ЗАРНИЦА | Уже присутствует; «ЗАРЕВО» представляет самостоятельное явление |
| ПЕРВЫЙ ЗВОНОК | Уже «ШКОЛЬНЫЙ ЗВОНОК» — близкий игровой эпизод |
| ЧЁРНАЯ ДЫРА | Дословно присутствует |
| ЛОЖНАЯ ТРЕВОГА | Дословно присутствует |

Осмысленно разделены: «ПЛОМБА» — стоматологический материал, не «АПЛОМБ» и не «ПЛОМБИР»; «ЗАРЕВО» — свечение от света/огня, не мираж «МАРЕВО»; «ЩЕПКА» — деревянный осколок, не «ПРИЩЕПКА»; «КНИЖНЫЙ ЧЕРВЬ» — увлечённый читатель, не «КНИЖНЫЙ КЛУБ». «ПЕРВАЯ ЛЮБОВЬ» — период или переживание, не общее понятие «ЛЮБОВЬ». Сложные карточки включают доступные для объяснения исторические и культурные термины; редкость слова сама по себе не считается достоинством.
