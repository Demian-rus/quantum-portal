## Проверка и решения редактора

Первичный отсев: **216 вариантов отдельных слов и 65 вариантов словосочетаний**. В итоговый набор попали 50 карточек, не встречающихся после нормализации (NFKC, регистр, ё→е, пробелы и знаки препинания) среди **6176 предыдущих текстовых карточек**. Все постоянные ID новые. Автоматическая проверка не доказывает полного отсутствия смысловых повторов — подобные случаи рассмотрены вручную.

| Исключено | Причина |
| --- | --- |
| ШОРОХ | Уже существует отдельная карточка, обнаружено при повторной сверке |
| АРБИТРАЖ | Слишком близкая игровая ассоциация к уже существующему «АРБИТР» |
| ИСКРА | Уже «ЭЛЕКТРИЧЕСКАЯ ИСКРА» |
| ПЕРЕЙТИ РУБИКОН | Дословный повтор |
| ВСПЫШКА МОЛНИИ | Уже используется центральный образ вспышки |
| ПРИМЕРКА КОСТЮМА | Избежали сценарной близости к отдельной «ПРИМЕРКА» |

Допустимые близости с иной игровой сутью: «ОПУШКА» — край леса, не «ХЛОПУШКА»; «ТАБУН» — стадо лошадей, не «ТАБУ»; «ФЕРМАТА» — музыкальный знак, не «ФЕРМА»; «ЗАСТАВА» — охранный пост, не «ЗАСТАВКА». «КАПЕЛЬ» и «КАПЕЛЬДИНЕР» не синонимы. Уровень hard содержит различимые при объяснении термины («катакомбы», «перигей», «верлибр») и более специфичные («палимпсест»); редкость сама по себе не является достоинством.
