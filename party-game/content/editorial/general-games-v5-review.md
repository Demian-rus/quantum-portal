# VG5 — узнаваемые игры и слова для широкой аудитории

## Решение после обратной связи владельца

Владелец отметил, что даже ему, многолетнему игроку, большая часть редких имён и терминов из прежних VG1–VG4 незнакома. Поэтому для **VG5** главный критерий — человек, который вообще не играет в компьютерные игры, должен иметь шанс распознать или объяснить карточку без энциклопедических знаний.

**Преимущество узнаваемости перед квотой сложности.** В VG5 50 карточек: 40 одиночных слов, 10 словосочетаний, 45 лёгких / 5 средних / **0 сложных**. Не вводить редкие имена боссов и NPC или сложный геймерский жаргон ради количества.

Все игровые тексты и имена примеров — только кириллица. `meta.game` обозначает пример связанной игры; большинство игровых слов (бонус, уровень, пауза, босс, сохранение) встречаются во многих играх и не считаются эксклюзивными для указанной.

## Проверка и ограничения

- Все 50 точных нормализованных текстов предварительно сверены с **59 исходниками** общих и исторических карточек. Отсеяны уже существующие «ДЖОЙСТИК», «КОНСОЛЬ», «ПИКСЕЛЬ», «АРКАДА», «САПЁР», «КОСЫНКА» и другие. Новые карточки не повторяют существующие тексты.
- Потенциальные **семантические** пересечения с общими понятиями допускаются только там, где это действительно особая игровая ассоциация. Не использовать почти одинаковые пары в одной новой редакции: например, «ПРИСТАВКА» без «ИГРОВАЯ ПРИСТАВКА»; «БОСС» без «ГЛАВНЫЙ БОСС»; «ЗМЕЙКА» — самостоятельное название игры.
- `general@54` = 7 220 ID; `general@55` = **7 270** ID, все предыдущие закреплены в исходном порядке; VG1–VG5 дали 250 новых игровых заданий. Не менять старые партии.
- Дальнейшая редактура **уже подготовленных VG1–VG4** необходима до публикации: часть из 200 заданий слишком узкая для общего словаря. Рассмотреть исключение редких героев/жаргона из последующей фиксированной версии общего набора, **сохранив их исходные ID и архивные версии**; пригодные для будущей специализированной темы хранить отдельно. Это отдельное изменение, без автоматического массового удаления.
- Источники не меняют runtime, PWA, профили и Work TASK034. PR держать Draft до интеграции с main.

### Уточнение примеров

Для приставок и брендов `meta.game` содержит именно пример известной **игры**, а не название самой приставки. Для «АПТЕЧКА» взята «ХАЛФ-ЛАЙФ» (в Counter-Strike восстановление здоровья аптечкой не является обычной механикой). Для «ПРОХОЖДЕНИЕ» — «СУПЕР МАРИО», а не «ТЕТРИС», у которого нет обычного сюжетного завершения.
