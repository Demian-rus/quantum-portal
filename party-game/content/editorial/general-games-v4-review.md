# VG4 — четвёртая партия категории «Видеоигры»

**Цель.** Продолжаем `videogames` в общем словаре. Ни новой тематической партии, ни нового режима не создаём. В будущем можно использовать карточки для полноценной темы, сохраняя прежние ID.

- Ровно **50 новых карточек**: 40 одиночных слов, 10 словосочетаний, сложность 20 лёгких / 20 средних / 10 сложных.
- Все тексты и примеры названий игр (`meta.game`) написаны **только кириллицей**. Слова с дефисом являются одним словом без пробелов.
- `meta.game` указывает игру, с которой связано задание. Для общих понятий это лишь иллюстративный пример, не эксклюзивная принадлежность.

- `general@53`: 7 170 ID, `general@54`: **7 220** ID. Все 7 170 предшествующих ID сохранены в точном порядке; ни один старый каталог не модифицирован.
- Содержимое категории после VG1–VG4: **200 новых игровых заданий**.
