## Отбор и самостоятельность заданий

Сформирован пул **285 кандидатов на отдельные слова и 79 словосочетаний** в разных тематических блоках. На этапе точной нормализованной сверки отсеяны использованные карточки; финальные **50** проверены против **6276 предыдущих текстовых карточек**, включая G31, с результатом **0 точных нормализованных повторов**. Повторной проверкой штатных near-критериев (общие слова и триграммы) не выявлено новых пар с выбранными G32. Автоматический аудит не гарантирует полного отсутствия семантической близости.

| Отсеянный кандидат | Причина |
| --- | --- |
| КОЛЛАЙДЕР | В каталоге уже есть «АДРОННЫЙ КОЛЛАЙДЕР», почти та же ассоциация |
| ПРОЛИТЫЙ ЧАЙ | Очень близкий сюжет к уже существующему «ПРОЛИТЫЙ СОК» |
| ГРАБЛИ | Уже есть «НАСТУПИТЬ НА ТЕ ЖЕ ГРАБЛИ» с тем же центральным предметом |
| ПЛЕТЕНЬ | Уже присутствует в «НАВОДИТЬ ТЕНЬ НА ПЛЕТЕНЬ» |
| ГЕНЕРАЛЬНАЯ РЕПЕТИЦИЯ | Близкий сценарий к театральной репетиции из прежнего каталога |
| ПАПОРОТНИК | Уже используется отдельным словом в существующем словаре |

Допустимые различия: «РУКАВ» — часть одежды, не «РУКАВИЦА»; «ГРАФИН» — посуда, не «ГРАФИТ»; «ПИЦЦИКАТО» — музыкальный способ извлечения звука, не «ПОЛИФОНИЯ» (фактура музыки); «ПРИНЦ НА БЕЛОМ КОНЕ» — узнаваемый романтический образ, не общая категория сказочных персонажей. «СЛОН В КОМНАТЕ» — очевидная замалчиваемая проблема, не «СЛОН В ПОСУДНОЙ ЛАВКЕ» (неловкое поведение). «ЗОЛОТОЙ ПАРАШЮТ» обозначает компенсацию руководителю при увольнении, не запасной парашют.

Уровни сложности требуют полевой оценки игроков; редкость слов сама по себе не является достоинством.
