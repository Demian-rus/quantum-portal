# ИСКРА ✳
Отдельная браузерная игра внутри репозитория Quantum Portal, независимая от его кода.

**Запуск:** откройте `party-game/index.html` или запустите простой локальный HTTP-сервер. Публичный адрес после публикации GitHub Pages: `https://demian-rus.github.io/quantum-portal/party-game/`.

## Правила
Две команды по очереди бросают шестигранный виртуальный кубик: **Говори, Покажи, Рисуй, Напой, Секретка, Блиц**. Ведущий команды смотрит секретную карточку, запускает таймер (45, 60, 90 секунд; блиц всегда 30), объясняет слово или выполняет задание, а после окончания раунда судьи нажимают зелёную галочку или красный крестик. Обычный раунд приносит 1 очко, секретный — 2. Побеждает команда, набравшая больше очков после выбранного количества ходов.

Возможно играть на одном телефоне, без аккаунтов и сервера. Состояние партии хранится в `localStorage`, поэтому сохраняется после перезагрузки. Звуки синтезируются Web Audio API после действия пользователя. Оформление — CSS-анимация + собственная SVG-иллюстрация `assets/hero.svg`, не зависящая от сторонних картинок.

## Изменение контента
`words.js` содержит 360 общеигровых слов/фраз и 90 тем для песенного режима, три уровня сложности. Перед добавлением слов убедитесь, что в одной подборке нет повторов.

## Проверки
`node --test party-game/tests/logic.test.cjs` — логика партий, таймера, очков и сохранения. `node party-game/tests/browser.cjs` — Chromium с Playwright (установить `playwright-core`, нужен Chrome).

## Структура
- `index.html` — доступная разметка меню и игровых сцен
- `style.css` — адаптивные стили
- `app.js` — игровой автомат состояний, таймер, аудио и сохранение
- `words.js` — наборы слов
- `assets/` — исходные векторные иллюстрации
- `tests/` — проверки

Никаких сборщиков, серверных функций или платных зависимостей для самой игры не нужно.
