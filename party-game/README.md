# КВИП — игра для двоих на одном телефоне

**Играть:** https://demian-rus.github.io/quantum-portal/party-game/

КВИП — офлайн-доступная браузерная игра (PWA): один игрок загадывает, второй отгадывает. На следующем ходе роли меняются. Выбирайте режимы, сложность, цель партии и получателя очков; зарабатывайте очки, выполняйте усложнения и при желании включайте риск-раунды.

## Как играть

- Игра на одном устройстве для двух игроков/команд. Загадывающий видит карточку и выполняет задание, отгадывающий не должен заранее видеть ответ.
- В настройках выбирается, **кому начислять очки**: загадывающему (обычное значение) или отгадывающему. Роли и получатель награды — разные понятия.
- Играйте до целевого количества очков (обычно 25, с обязательным ответным ходом) либо фиксированное чётное число ходов. При нужной ничьей применяется существующий тай-брейк.
- Лёгкая сложность допускает ручной запуск таймера, паузу и замену карточки. На средней и сложной таймер запускается автоматически; обычная пауза недоступна.
- Для новых партий используются правила, действующие при их создании. Уже начатые партии не должны менять таблицы наград, наборы заданий или режимы при обновлении приложения.

### Режимы

| Режим | Что делает игрок |
| --- | --- |
| **Слова** | Объясняет слово, не называя его и однокоренные |
| **Жесты** | Показывает задание без слов |
| **Нарисуй** | Изображает задание рисунком |
| **Напой** | Напевает песню со словом из карточки |
| **Данетки** | Загадывающий отвечает на вопросы, отгадывающий узнаёт персонажа |
| **Секретка** | Один из способов плюс обязательное усложнение |
| **Блиц** | Серия коротких слов за общий таймер, с особой системой зачёта |
| **Примерно** | Оба называют число, затем вручную выбирают, кому начислить очки |

Есть **Стандартная** игра с общим набором и **Тематическая** с отдельными наборами. Доступные режимы и типы карточек зависят от темы: пустая категория не подменяется общим словарём. Тонкая настройка позволяет выбирать режимы, разновидности контента и некоторые их индивидуальные параметры. Точные баллы и ограничения выводятся в игре и зависят от сохранённой версии правил.

### Риск и усложнения

- Риск-раунды в опубликованной **v85** используют независимую вероятность около **20% на подходящий ход после первых двух ходов**. Неудача может снять до двух очков с выбранного получателя, но не опускает счёт ниже нуля. Эта текущая система **пока не гарантирует** равенства риска между игроками. Переработка: [Issue #100](https://github.com/Demian-rus/quantum-portal/issues/100).
- Случайные усложнения имеют отдельные настройки. Для них, где предусмотрено правилами, результат может быть: не угадали, угадали без усложнения, выполнили вместе с усложнением. `Секретка` всегда использует усложнение; `Примерно` — без таймера и риска.

## Профили, история и сохранения

- Можно создать **профили игроков** для накопительной статистики на одном телефоне. Профили и их статистика хранятся **локально на этом устройстве**, а не в онлайн-аккаунте.
- В игре **v85** нажмите на верхнюю плашку игрока, чтобы увидеть историю его результатов и исправить ошибочно выбранный исход. Изменения пересчитывают баллы по сохранённым правилам всех ходов.
- Перед завершением **новой** партии открывается обязательная **«Проверка результатов»**: переключайтесь между игроками, исправляйте последний или предыдущие ответы, затем нажмите **«Подтвердить результаты»**. Только после подтверждения победа записывается в постоянную статистику. Старые завершённые партии не редактируются задним числом.
- В **Настройках** есть экспорт/импорт резервных копий профилей и статистики с проверкой и защитой от случайной перезаписи. **Текущая незавершённая партия в такой экспорт не входит.**
- Незавершённая партия хранится отдельно и восстанавливается через «Продолжить», включая необходимые состояния таймера. Если данные повреждены, действуют защитная блокировка и отдельная процедура восстановления вместо тихого сброса.
- Ключ сохранения партии `iskra-party:v1` сохранён намеренно для совместимости. Не переименовывайте его без специальной миграции.

Подробные технические контракты: [PLAYER-PROFILES.md](PLAYER-PROFILES.md), [PROFILE-BACKUP.md](PROFILE-BACKUP.md), [TASK020-RESULT-REVIEW.md](TASK020-RESULT-REVIEW.md), [ARCHITECTURE.md](ARCHITECTURE.md).

## Оценки заданий: палец вверх / вниз

У таймера есть зелёная кнопка одобрения и красная кнопка жалобы. Жалоба приостанавливает отсчёт до закрытия формы, где можно выбрать причину и написать комментарий.

**Важно:** в v85 нажатие **не отправляет голос в GitHub и не отправляет его нам автоматически**. Одобрения и жалобы остаются в локальных журналах устройства. В **Настройках → Оценки заданий** есть «Поделиться статистикой заданий» (Android Web Share, если поддерживается) и «Скачать JSON»; это один файл с оценками **без имён профилей и результатов партий**. Очистка данных сайта может удалить неэкспортированные оценки. Планируемая автоматическая синхронизация — [Issue #110](https://github.com/Demian-rus/quantum-portal/issues/110).

## Установка и обновления

Откройте адрес игры в Chrome на Android и выберите «Установить приложение» / «Добавить на главный экран». После первой успешной загрузки PWA кэширует игровой код и изображения для офлайн-игры. Новая версия публикуется из `main` через GitHub Pages; иногда потребуется закрыть и заново открыть установленную игру для применения обновлённого service worker.

Тесты Chromium не заменяют окончательную проверку на физическом Android.

## Файлы и архитектура для разработчиков

| Путь | Назначение |
| --- | --- |
| `content/` | Редактируемые JSON карточек, вопросов, усложнений, версий наборов и редакционные ведомости |
| `scripts/content.cjs` | Генерация и проверка статических runtime-файлов из исходного контента |
| `cards.js`, `content-packs.js`, `approx-questions.js` | Генерируемые ресурсы; при контентных правках следовать [CONTENT-WORKFLOW.md](CONTENT-WORKFLOW.md) |
| `rules.js`, `penalties.js`, `round-planner.js`, `round-selection.js` | Правила, риск и выбор задания |
| `round-settlement.js`, `result-review.js`, `result-review-view.js` | Начисления, детерминированное исправление и подтверждение итогов |
| `player-profiles.js`, `profile-backup.js`, `storage-controller.js`, `session-restoration.js` | Профили, резервные копии и защита сохранений |
| `card-reports.js`, `card-feedback.js`, `card-feedback-view.js` | Локальные жалобы, одобрения и экспорт |
| `index.html`, `style.css`, `sw.js` | Экран приложения, стили и офлайн-кэш |
| `tests/`, `.github/workflows/quip-game.yml` | Логические, браузерные, мобильные и PWA-проверки |

Полный проект включает и другие части Quantum Portal; для разработки КВИП работать в `party-game/`.

### Минимальные проверки из корня репозитория

```bash
node party-game/scripts/content.cjs check
node --test party-game/tests/logic.test.cjs
node party-game/tests/mobile-layout.cjs
node party-game/tests/browser.cjs
```

Полный обязательный набор (Logic, Browser, Gameplay/Smoke, PWA upgrade/offline) указан в [`.github/workflows/quip-game.yml`](../.github/workflows/quip-game.yml) и других workflow. Браузерным тестам нужны Chromium, `playwright-core` и локальный HTTP-сервер; ориентироваться на конфигурацию CI.

**Правило публикации:** Word/JSON-редакторы и ChatGPT Work готовят **отдельные Draft PR**. Архитектор сверяет актуальные SHA, выполняет независимый аудит, тестирование и merge. Обновление каталогов требует согласования `index.html`, `sw.js`, версий ресурсов и сохранения всех старых идентификаторов. Подготовленные 500 новых карточек из [PR #111](https://github.com/Demian-rus/quantum-portal/pull/111) **ещё не являются частью опубликованной v85**.
