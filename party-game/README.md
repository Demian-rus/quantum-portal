# КВИП V5 — дуэльная игра на одном телефоне

**Играть:** https://demian-rus.github.io/quantum-portal/party-game/

Самостоятельная статическая PWA внутри репозитория Quantum Portal. Сервер, регистрация, реклама и сторонние API не нужны. Вся партия хранится локально в браузере.

## Главное правило 1 на 1

В каждом ходе один игрок **загадывает** (видит задание, объясняет, рисует или отвечает на вопросы), а второй **отгадывает**. Очки получает **отгадывающий**. На следующем ходу роли меняются. Под игровыми именами в табло показаны роли текущего хода; подсвечивается именно отгадывающий.

На одном телефоне загадывающий держит экран так, чтобы соперник не увидел ответ. В «Данетках» он отвечает «да», «нет» или «не знаю», а соперник пытается угадать персонажа.

## Семь режимов

| Режим | Условия | Очки |
| --- | --- | --- |
| Слова | Объяснить, не произнося ответ и однокоренные слова | 1 |
| Жесты | Показать жестами без слов и звуков | 2 |
| Нарисуй | Нарисовать на бумаге, без букв и цифр | 2 |
| Напой | Напеть песню по теме, чтобы угадали тему | 2 |
| Данетки | Угадать человека/персонажа вопросами «да/нет» | 2 |
| Секретка | Один из пяти базовых способов и обязательное усложнение | 3 |
| Блиц | Отгадать **все пять** слов за 30 с | **3 только за 5/5**, иначе 0 |

Пропуск в Блице возвращает слово в конец очереди. Каждое из пяти слов учитывается только после первого правильного ответа. Полного результата не достигли — очков за Блиц нет.

«Секретка» берёт один из включённых основных режимов. Если включена только «Секретка», она использует любой из пяти способов; это намеренное правило. В остальных случаях отключённые базовые режимы в неё не попадают.

## Завершение партии

По умолчанию партия играется **до 25 очков**, целевое значение — от **15 до 100**, шаг 5, задаётся ползунком в тонкой настройке. Достигший цели игрок не выигрывает немедленно: второй обязательно получает **ответный ход**. Итог подводится после полной пары ходов. Если после неё счёт равный, игра продолжается парами до определения победителя.

В тонкой настройке можно выбрать вместо цели **количество ходов**: от 2 до 100, только чётное число, чтобы у соперников было одинаковое число попыток. Если финальный счёт равный — ничья.

## Время и сложность

Ползунок времени задаёт базовые **30–90 с** для «Слов», с шагом 5 с. При обычном базовом времени 30 с:

- Слова — 30 с.
- Жесты и Напой — 45 с.
- Нарисуй и Данетки — 60 с.
- Секретка — по выпавшему способу.
- Блиц — фиксированные 30 с.

На всех обычных режимах верхняя граница — 90 с. На лёгкой сложности можно менять карточку, самостоятельно запускать таймер и делать паузу. На средней и сложной отсчёт начинается через секунду после открытия задания; замена и пауза недоступны. «Микс» выбирает уровень каждого раунда отдельно.

## Риск-раунды ⚡

По умолчанию включены. После первых двух ходов с вероятностью около **20%** выпадает риск-раунд с заметным предупреждением: обычная награда за успешное выполнение либо потеря **до 2 очков** у отгадывающего при провале (включая неполный Блиц). Очки не опускаются ниже нуля. Риск-раунды можно отключить в тонкой настройке.

Случайные усложнения отдельно включаются/выключаются. В обычных режимах они выпадают примерно в 35% случаев, в «Секретке» — всегда.

## Задания и словари

Старые наборы хранятся в `words.js`, дополнительный ручной набор — в `extra-words.js`. Отбор объединяет оба набора и удаляет точные дубли по одному уровню сложности. Старые словосочетания, случайно оказавшиеся в одиночных словах, теперь доступны как фразы. Режимы «Напой» и «Данетки» используют отдельные наборы тем и персонажей.

База расширена, но она не является окончательно выверенной по частотности и пригодности каждого задания: нужна дальнейшая содержательная редактура.

## Устройство проекта

- `index.html` — меню, настройки, игровой экран, результаты и правила;
- `style.css` — адаптивный портретный UI, игровые карточки, неоновое оформление;
- `app.js` — игровая логика, роли, счёт, завершение, таймер, риск, Блиц и сохранение;
- `words.js`, `extra-words.js` — тексты заданий;
- `mode-images.js` и `assets/modes/*.webp` — семь отдельных иллюстраций;
- `assets/bg-*.webp` — три фоновых изображения;
- `sw.js` — офлайн-кэш;
- `tests/` — Node.js и Chromium проверки.

**Совместимость сохранений:** используемый ключ `iskra-party:v1` умышленно сохранён. Старые незавершённые партии продолжают прежний режим подсчёта по `scoringVersion`, новые используют версию 2. При публикации нового релиза нельзя просто менять этот ключ.

Установка как PWA: открыть сайт в Chrome на Android и выбрать «Установить приложение»/«Добавить на главный экран». `display:standalone` убирает обычную браузерную панель, а сервис-воркер кеширует игровые файлы и изображения.

## Проверки

```bash
node --test party-game/tests/logic.test.cjs
node party-game/tests/browser.cjs
node party-game/tests/v2-browser.cjs
node party-game/tests/immersive.cjs
node party-game/tests/polish.cjs
```

Браузерные тесты требуют установленного Chromium, `playwright-core` и локального HTTP-сервера на порту 8765. GitHub Actions запускает проверки в CI, но проверку руками на физическом Android они не заменяют.
