## Android до публикации

Основная PWA продолжает открывать опубликованный main. Ветка не опубликована.
Для приватного HTTPS-просмотра откройте ветку PR в GitHub Codespaces,
запустите `python3 -m http.server 8765 --bind 0.0.0.0` в корне, откройте
порт 8765 в разделе Ports с видимостью Private и перейдите по выданному HTTPS-URL
на телефоне под своим аккаунтом GitHub, дописав `/party-game/`.
Обычный `file://` и HTTP по локальному IP не подходят для полноценной PWA-приёмки.

PR остаётся Draft. Main и опубликованная PWA не изменены.
