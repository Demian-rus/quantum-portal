# TASK 021 — UX hotfix, кандидат PWA v84

База: опубликованная v83, `363b9aa1e33f47f5484d438d6fc49f57c7c12c0a`. Только новый Draft, без merge и публикации. #94/#98/#99/#102/#103 и 400 неопубликованных карточек не изменяются.

## Интерфейс

На всех обычных стадиях раунда (ready, rolling, task, countdown, play, judge, between, results) шапочный флажок скрыт, disabled, tabindex=-1 и aria-hidden=true. Его обработчик обслуживает только отдельный тай-брейк. Текущий раунд оценивается двумя кнопками у таймера; история результатов, тай-брейк и журнал настроек сохраняют реальные точки входа. Возврат фокуса выбирает видимую оценку либо меню, не скрытый флажок. Хранилища/ID/форматы отзывов не меняются.

Полный воспроизводимый аудит `CONDITION-AUDIT.json`: **112 V1 + 51 V2**. V1 остаются буквально прежними. Все 10 V2 с alternative покрыты точными presentation aliases, включая базовые исторические варианты без склеенной альтернативы. Ещё два сокращения убирают оговорки у closed-mouth и volume-change. Всего 12 отображаемых вариантов; у fists/one-arm/elbows/wrists/fixed-feet дополнительно сокращены удобные положения и факультативные пояснения. Содержательные запреты, бюджеты подсказок, условия следующей попытки и трактовка повторов сохранены.

Подмена требует совпадения version=2, ID и полной исходной строки из явного списка. Нет regex-очистки произвольного сохранённого текста; неизвестные пользовательские/исторические строки остаются буквально прежними. Видимый текст и title используют один display-вариант; aria не содержит спрятанной исходной оговорки. Исходные каталоги, generated JS, complication/complicationId и история не переписываются. `node party-game/scripts/condition-audit.cjs check` сверяет полный аудит.

Раскладка использует фактическую высоту панели через CSS container queries. Три зоны stable-round: верхний контент, фиксированная карточка, фиксированная высота результатов. Между зонами зарезервированы 24 px (20 px на маленькой панели), с запасом для вращения border box и тени. Удалён старый дополнительный footer-space=90px. На узком экране адаптивно уменьшаются карточка/шрифт/таймер/иллюстрация, без изменения таймера как механизма. У обычного текста нет внутренней прокрутки; для чрезвычайно длинного неизвестного исторического условия остаётся доступная прокрутка верхнего региона, ограниченная своей зоной.

Landscape: общая верхняя строка разделена на блок условия/таймера и карточку. Внутри левой зоны условие и dial стоят рядом; краткий countdown занимает всю ширину. Иконка и название task стоят в одной строке. Нижние результаты имеют собственную строку. Это распределение пространства, без отрицательных margins или случайных сдвигов карточки.

## Проверки

Новый browser suite измеряет **фактические transformed border boxes** карточки, полного SVG/dial, текста таймера, ratings и нижних controls. Требует ≥12 CSS px между ними (горизонтально между колонками landscape), touch ≥44px, отсутствие пересечений/выхода за viewport/scroll текста карточки. Task→countdown→play отклоняется ≤2px. Проверены Жесты, Секретка:Слова, Напой, Секретка:Напой, Блиц с риском, обычный раунд с 2/3 результатами, длинная фраза, все 51 V2 на 320px и дополнительное потребление safe areas. Размеры: **320×568, 360×640, 390×844, 412×915, 844×390**. Все измерения пишутся в `artifacts/quip-task021/geometry.json`.

Сравнения `before/after-{task,play}-{320,360,390,412,844}.png` используют один и тот же детерминированный fixture и точные bytes опубликованной v83 для before. Изображения проверяются визуально, включая 320/390 и landscape.

Node regression проверяет все 163 display/source пары, 10 base-only вариантов альтернатив, title/aria, сохранность содержательных вторых предложений и отсутствие RNG/записей. Отдельный guard побайтно сравнивает все content-файлы, generated catalogs, RNG/settlement/clock/hold/storage/profile/backup модули с v83.

Старые Browser проверки жалоб перенесены с удалённой кнопки на настоящие кнопки истории результатов; сохранены открытия/Back/Escape/Tab/ID/редактирование/удаление/очистка/экспорт и отдельные активные timer holds. Полный UX/feedback сохраняет restart, обе оценки и Web Share API. Старые требования вертикального заголовка landscape заменены проверкой горизонтального отсутствия пересечений; на узком экране рост карточки уступает явно заказанному адаптивному уменьшению с проверкой читаемого минимума. Остальные assertions не удалены.

Сохранены все прежние обязательные Logic, Gameplay/Smoke и Browser/upgrade/offline. Добавлен реальный **v83→v84** warm worker/cold offline reload: старая партия содержит compiled alternative, после обновления её RAW, профили, результаты, taskMemory и журнал буквально сохраняются, а UI показывает короткую формулировку. Проверены Resume/остаток, закрытие жалобы, SHA-256 и оба JSON-экспорта. Существующие v75/v78 и legacy upgrade остаются обязательными.

URI HTML/SW: style.css v41, round-presentation.js v7, card-reports-view.js v4. Остальные 45 JS и content URI прежние. Cache `kvip-pwa-v84-20261025-ux-hotfix-candidate`. Новый cache — кандидат, не публикация.

## Границы
