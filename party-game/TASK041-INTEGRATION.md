# TASK041 — интеграция quip@1

## Этап A

Новые 1×1 и 2×2 фиксируют `contentPack.selectionPolicyVersion:2`, точную редакцию и её digest, а также независимый `taskDifficultyPolicy.version:1`. Старые каталоги и отсутствие новой политики сохраняют исторический подбор. Старый читатель отклоняет новую форму selectionPolicyVersion вместо игнорирования сложности при rollback.

Режимные оценки используются независимо от общей сложности раунда (награды, таймеры и тяжесть модификаторов не изменены). Секретка пересекает собственную политику с политикой фактического метода; источник методов не расширяется после фильтрации. Блиц выбирает три различных слова, по умолчанию medium/hard. Песни и числовые вопросы используют свои пулы. Общая taskHistory сохраняет прежние ID и нормализованные ключи повторов.

Числовой тай-брейк остаётся самостоятельным конкурсом с прежним начислением. У новых партий он использует числовую редакцию, категории и политику «Примерно»; заданный уровень не подменяется. Исторические партии сохраняют прежние числовые пулы и порядок уровней.

Целевой runtime-контроль: 45 PASS / 0 FAIL (все три уровня прямых режимов в обоих форматах, Секретка, пустые пулы, неизвестные версии, независимость будущих настроек и исторического RNG). Это ещё не финальная приёмка и не публикация.

## Этап B

В существующий центр «Настройки режимов» добавлены независимые уровни всех восьми режимов. Рисование и жесты стартуют с easy, Блиц с medium/hard; явный all поддерживается. «По способу выполнения» применяется к Секретке. Недоступные сочетания отключены с объяснением, выбранная политика не меняется автоматически. Сводка на «Старт» перечисляет выбранные уровни.

Настройки следующей партии живут в отдельном guarded-слоте `kvip:mode-difficulty:v1`, общем для 1×1 и 2×2. Они не изменяют RAW текущей партии. Неизвестная версия не перезаписывается. Все новые runtime-файлы включены в PWA-кэш v111.

## Этап C — совместимость и причины CI

Исправлена проекция источника замечаний для selectionPolicyVersion:2. История замечаний сохраняет прежний формат и ID. Выбор тем и счётчики теперь используют ту же редакторскую политику, что и START. Проверены отсутствие записей в текущий RAW при смене будущих уровней, восстановление выбранных ID, исторические v1–v6 и версии песенных политик.

Исторические фикстуры явно удаляют новые opt-in поля при построении старой партии. Тестовые тематические наборы получают собственную согласованную редакцию, а изменённый каталог без такой редакции отклоняется до RNG. Новая редакция содержит иностранные easy-песни: прежнее предположение об их отсутствии заменено проверкой настоящего пустого пересечения с исключённой категорией «Музыка».

Сохранены точные защитные сравнения старых исходников: новый normalizer обращает только перечисленные TASK041 hunks, а отдельные отрицательные проверки ловят изменения вне и внутри этих hunks. Покрытие PWA увеличено с 54 до 56 скриптов с обязательным присутствием каждого ресурса. Повреждённые и неизвестные версии настроек не перезаписываются.

Нагрузочная фикстура TASK038 теперь устанавливает согласованные метаданные quip@1 для synthetic general@1000. Размер малого прогона — реальный текущий каталог 7 460 заданий, большого — 15 000; исходные карточки не изменяются. Пороги остаются median ≤200 мс, p95 ≤350 мс, CPU4, n20. Повторные read-only подсчёты используют кэш неизменяемых пулов; START продолжает вызывать настоящий полный валидатор.

Целевые проверки на этапе исправлений: 83 PASS / 0 FAIL по runtime, командам, TASK035/039 и Touch; 8 PASS / 0 FAIL по адресным историческим фикстурам; 2 PASS / 0 FAIL по точным hunks и Блицу/тай-брейку. Это промежуточные результаты. Финальная обязательная матрица и мобильная приёмка должны подтвердить итоговый кандидат.

## Кандидат браузерной приёмки

Исправлено создание следующей партии после восстановления командного каталога старой версии: обновляется только черновик «Мастера», действующий снимок не меняется. Установленную тему с пустым текущим пулом можно открыть для настройки; уровень не подменяется, START остаётся заблокирован до допустимой комбинации. Выбранный недоступный режим можно выключить.

Устранён двойной учёт числовых карточек в synthetic perf-фикстуре: размеры подтверждены отдельно как 7 460 и 15 000. Исторический v88-прогон использует API своего развёртывания до upgrade. Браузерные проверки наблюдают настоящий редакторский селектор; тематические сценарии явно выбирают доступный medium вместо недоступного easy/mixed.

PWA-кандидат v113 включает актуальные версии всех ресурсов. Целевые тесты этих исправлений: 67 PASS / 0 FAIL и ещё 3 PASS / 0 FAIL по входу в тему без автоматической подмены уровня. Полная матрица остаётся обязательной; эти числа не заменяют её итог.
