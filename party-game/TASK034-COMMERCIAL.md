# TASK034 A — коммерческий каркас без изменения действующей игры

Issue: https://github.com/Demian-rus/quantum-portal/issues/186

Исходный подтверждённый Base: `4b84dc88bc39e0b0b4145dce240a0a66d964248a` (TASK028–033 и G46). После одобрения владельцем исходный независимый PR B #188 принят в main `89a980fce1c6361936b3a96b5b3412beb738a436`. PR A синхронизирован с этим принятым main: все его production-файлы `party-game/`, включая index, sw, manifest, словари, профили, статистику и движки, остаются побайтно прежними относительно 89a980fc. Внутри party-game добавлен только этот технический документ. SHA интеграции и точные CI фиксируются в существующем PR A #187.

Полный контракт, границы и инструкции: [commercial/README.md](../commercial/README.md).

| Требование | Реализация / проверка |
| --- | --- |
| Весь нынешний каталог бесплатен | Адаптер всех 67 версий, стабильные id/version, будущие бесплатные G без фиксированного лимита |
| Free/purchased/granted/owner | Серверная политика; fake-флаги клиента, другой account и просроченные grants не дают доступ |
| Бессрочный владелец / подарки | Trusted admin grant; wildcard owner включает новые наборы; grant+audit идемпотентны |
| Серверная выдача | Auth, действующие grants и audit до чтения материала; default fail-closed; API origin отделён от PWA cache |
| Подписанные права | Ed25519, account/key/time binding; snapshot не заменяет авторизацию контента |
| Разделение профилей | Ни одного обращения к localStorage/профилям/duel/team RAW из коммерческого каркаса |
| Premium/debug не в public | Явный allowlist, точный git SHA, замыкание HTML/CSS/SW ресурсов, только синтетические данные |
| Платформы | public-web; отдельная debug цель; Android/iOS только честно обозначенные шаблоны без APK/IPA |
| Публикация | Только dry-run с SHA256/размерами/планом; execute и облачные операции отсутствуют |
| Текущая PWA | Ни один ресурс/версия/cache name/manifest не изменён; существующий CI сохранён |

Базовый main CI: [Game checks](https://github.com/Demian-rus/quantum-portal/actions/runs/40720686272), [Smoke](https://github.com/Demian-rus/quantum-portal/actions/runs/40720686350). Его screenshots/geometry служат исходными доказательствами; принятые результаты адаптивности сохранены в PR #188. 29 октября владелец подтвердил нормальное отображение на телефоне девушки. Модель/ОС не переданы; это обратная связь о внешнем виде, а не заявление о полном физическом тестировании обоих устройств.

Реальный коммерческий запуск потребует перечисленных в основном документе auth/DB/payment/security/platform работ и отдельного разрешения владельца. 29 октября владелец отдельно одобрил объединение каркаса и адаптивности. Разрешение не включает публикацию, реальные облако/платежи/аккаунты, смену приватности или выпуск APK/IPA.

Интеграция после одобрения: единственное изменение коммерческой конфигурации — явное включение бесплатного responsive-layout.css из принятого main в public allowlist и уточнение sourceBase. Все остальные публичные/приватные границы и проверки замыкания сохранены. Коммерческий runtime в игру не подключён. Каркас содержит прежние 13 contract/security/build тестов; сборка и dry-run проверяются на точном SHA объединённого дерева. Точные CI — в описании PR A.
