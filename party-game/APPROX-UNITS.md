# Семантический аудит единиц «Примерно» — Issue #97

База: UX PR #98, `39b72c05a567be43db3f013319a1954a72632235`. Исходники не редактировались. PWA v81 — кандидат, без публикации.

## UI и сохранность

Единица из сохранённого q.unit показывается до ответа в обычном раунде и общем тай-брейке. Строка находится вне прокручиваемой области вопроса, поэтому видна и у очень длинного текста. Пустое значение не заменяется догадкой. Answer и note до раскрытия не выводятся. После раскрытия остаётся прежний числовой ответ с прежней единицей. Содержимое старого снимка имеет приоритет над актуальным каталогом.

Математика, выбор вопросов, награды и таймер не менялись. Эквивалентные устные единицы (например, 1 км и 1000 м) по-прежнему могут приниматься решением игроков через прежние ручные кнопки. Автоматического пересчёта ответов нет.

## «Васа»

Точный вопрос: approx-20130, content/questions/estimation-v2.json. Вопрос спрашивает пройденное расстояние до затопления в 1628 году; answer="1300", unit="м". Официальная хронология музея подтверждает около 1300 метров: https://www.vasamuseet.se/en/explore/vasa-history/timeline . Единица и постановка согласованы. Ошибка была в рендере; источник, ID, число и pack сохраняются.

## Полный автоматический аудит

Все девять question JSON из manifest: **648 записей**, из них **611 с единицей**, **37 пустых unit**, только в legacy-v1.json. Повторяющихся ID нет. Машинный список с ID, исходным вопросом, файлом, unit и причинами флагов: [APPROX-UNIT-AUDIT.json](APPROX-UNIT-AUDIT.json). Воспроизведение: `node party-game/scripts/approx-unit-audit.cjs`; проверка зафиксированного отчёта: тот же скрипт с `check`. Это аудит единиц, а не новая проверка всех фактических чисел.

## Все 37 пустых unit: ручное смысловое решение

В каждом случае вопрос сам называет счётную величину или явно задаёт единицу (месяцы). Пустая unit допустима; скрытого выбора метров/миль здесь нет. Ни одна строка не признана дефектом только из-за пустого поля. Подстановка «штук» была бы неуместной для месяцев, людей, способов и многих других формулировок. ## Кандидаты на будущую ручную редактуру

Отдельный список manualCandidates содержит **23 записи**: 17 единиц с масштабом «тыс./млн/млрд/трлн» и 6 специализированных сокращений. Это не доказанные дефекты. Для масштабных величин стоит проверить, достаточно ли явно вопрос просит ответ в указанном масштабе; для сокращений — нужна ли читателю расшифровка. Полные ID/формулировки/единицы/причины есть в JSON. Автоматически менять их, округление или единицы нельзя. Если архитектор подтвердит смысловой дефект, предложение должно получить новую редакцию каталога с сохранением исторического объекта.
