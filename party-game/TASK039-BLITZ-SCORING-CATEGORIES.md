# TASK 039 — Блиц, очки и тематическая разметка

## Баланс

Новые партии используют `rulesVersion:6` и `modeConfigVersion:2`. За ЖЕСТЫ, НАПОЙ и НАРИСУЙ начисляются по 2 базовых очка. Все исторические конфигурации v1–v5 оставлены неизменными; партии, сохранённые под старыми правилами, продолжают использовать старые начисления и исходный пул Блица.

В БЛИЦЕ новой партии остаются 3 уникальных однословных задания за общий таймер. Они выбираются из всех трёх сложностей, включая слова длиннее 12 символов, с прежней историей повторов и категорными фильтрами. Базовая награда Блица остаётся 2 очка за 3/3 (плюс усложнение по действующим правилам). Уровень сложности раунда по-прежнему участвует в выборе режима, таймера и усложнений, но не ограничивает уровень отдельного слова в Блице.

## Редакционный набор general@68

Предыдущая общая версия: `general@67`, 7460 заданий. Новая декларация `general@68` использует те же 7460 закреплённых ID и те же редакционные источники, без создания новых слов.

Для 2840 ранее не размеченных **активных** карточек подготовлены метки через `categoryOverrides`, которые применяются только в новом снимке каталога. Исходные исторические файлы, их SHA-256, текст, сложность и ID карточек не меняются. Старые партии продолжают использовать закреплённую версию набора, и их фильтры не переинтерпретируются.

Первичный объём меток по категориям (одна карточка может иметь несколько): культура 570; повседневная жизнь 430; язык 354; наука 300; еда 228; профессии 126; искусство 107; животные 100; география 93; технологии 84; транспорт 83; природа 78; биология 76; спорт 62; море 59; музыка 50; литература 31; космос 22; история 12; кино 5.

**Редакционная оговорка:** метки расставлены первичным тематическим проходом по существующим тематическим блокам и узнаваемым словам. Это не индивидуальная проверка смысла каждой записи. Особенно словосочетания и многозначные слова требуют дополнительного редакционного аудита; некоторые широкие классификации могут оказаться неверными. До утверждения нельзя считать `general@68` полностью вручную выверенным набором.
