## Ограничения и последующие действия

Независимая приёмка архитектора обязательна перед любым merge/публикацией. Физический Android, установленная PWA и настоящее системное меню передачи файлов требуют ручного прогона; Chromium проверяет Android-подобный browser history и Web Share API-контракт. Web Storage не предоставляет межвкладочный CAS; неподтверждённый rollback блокирует записи. Очень длинные исторические условия/вопросы имеют доступный scroll fallback. Смысловые флаги единиц в APPROX-UNITS.md остаются отдельной редакторской задачей, без изменения старых вопросов.

После приёмки использовать этот единый PR к main; судьбу исходных Draft определяет архитектор. Будущие музыкальные карточки и TASK 019/020 интегрируются отдельно. Эта работа не меняет main и не запускает публикацию.
