## Включение и немедленный возврат

После отдельного развёртывания этой ветки открыть адрес игры с `?setup=wizard`. В настоящих настройках приложения также есть кнопка «Новая игра: попробовать Мастер».

Мастер использует четыре этапа **Игра → Кто играет? → Правила → Старт**. Последний этап запускает настоящую партию. «Командами · скоро» отключена до завершения TASK 028; работающая первая поставка — 1 на 1.

Для мгновенного отказа нажать **«ПРЕЖНИЙ ВИД»** в шапке Мастера либо открыть тот же адрес с **`?setup=legacy`**. Работает и офлайн после установки комплекта. Параметр URL сохраняется после Android Back и reload; отдельного ключа предпочтений или поля в игровом сохранении нет. Старые сцены, контролы и маршрут не удалены.

Переключатель изменяет только представление и URL, без записи партии/профилей, без выборки заданий/RNG. Настройки следующей партии продолжают сохраняться штатными обработчиками `options`. Текущая незавершённая партия остаётся доступна через «Продолжить».

## Реализация и границы

`setup-wizard.js` загружается **после** штатного `app.js`, использует реальные элементы управления и их существующие обработчики. Обратимые адаптеры касаются только `setScene`, `backWithinKvip`, `renderOptions`; при выключенном флаге они делегируют прежнее поведение. Игровой рендер, создание матча, сохранения и расчёт результатов не подменяются.

- Те же кнопки `standard-game`, `thematic-game`, `theme-list` вызывают существующие каталоги и проверку доступности.
- `team-a`, `team-b` открывают настоящий выбор/создание профиля. Старт использует прежний `selectedPlayerProfiles()`/`reserveProfileMatch()`.
- Настройки физически переносятся в этапы, а при возврате вставляются в исходные позиции. ID не дублируются, слушатели и контроллеры остаются прежними.
- Плитки Мастера строятся по `MODE_LIST`, обработка checkbox остаётся у `registerSetupControls()`; первоначальная разметка с шестерёнками возвращается в старом интерфейсе.
- Один центр правил показывает все режимы через действующие `rulesGuidePage()`/`getModeConfig()`, награды и время читаются из реестров. Русские/иностранные источники «Напой» — те же реальные кнопки и `selectSongLanguage()` с настоящей валидацией набора и непустого выбора.
- `start-game` — исходная кнопка с исходным обработчиком `newGame()`. Нет копии движка, лабораторных имён, имитации таймера или статических каталогов из lab.
- Исправлено только актуальное описание Блица. Старый `QUIP_LEGACY_MODES.blitz.rule` явно сохранён прежним; все остальные параметры старых и новых режимов сравниваются целиком с базой.
- `setup-wizard.css` ограничен новой сценой. **Исходный `style.css` и принятая игровая сцена v88 побайтно сохранены.**

Изменения подключений: один новый JS, один отдельный CSS, `mode-config.js?v=3` вместо v2 из-за пользовательского текста; оба новых ресурса входят в precache. Все 48 исходных JS-контроллеров побайтно сохранены, кроме точно проверенного изменения описания Блица. Rulesets, RNG, профили, долговременная статистика, history, backups и словари не меняются.

## Точная процедура отката

1. **Без развёртывания:** на кандидате открыть `?setup=legacy` либо нажать «ПРЕЖНИЙ ВИД». Продолжить незавершённую партию через прежнее меню. Проверено без изменения байтов сохранения при самом переключении.
2. **Перед первым merge:** архитектор сверяет, что контрольный production SHA всё ещё `507c3d24f270a7d26b1562ffc6837c819a15aa5b`, или фиксирует новый фактический production SHA при изменении main. Создаёт защищённый контрольный релизный тег на этом SHA. Work не выполняет merge или выпуск.
3. **Откат приложения целиком:** из актуального main отдельным проверенным PR отменить коммит(ы) TASK 027. Вернуть контрольные HTML/JS/CSS и отсутствие подключения Мастера. Если другие принятые изменения появились позже, применять `git revert` именно коммитов TASK 027, не заменять main старым деревом целиком.
4. Выпустить SW с **новым уникальным именем кеша отката** и ресурсами согласованного старого комплекта; проверить precache и холодный offline. В автоматическом тесте дополнительно подтверждено восстановление точного исходного v89 SW. Сеть нужна один раз для получения откатного комплекта.
5. Не удалять site data, localStorage, профили, оценки, `iskra-party:v1` или recovery. Старый код читает те же `version:1`/`rulesVersion`/каталоги: новых полей матча и миграции здесь нет.
6. Проверить на физическом Android: продолжение приостановленного задания, заработанные очки/историю, исправление результатов, один учёт завершения, темы и выход/Back. Только после этого считать выпуск/откат принятым.
