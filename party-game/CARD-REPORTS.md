# TASK 017 — замечания к заданиям

Небольшой флажок в шапке игрового поля находится вне кнопки карточки. Он доступен для выбранного задания в task/countdown/play/judge и общего тай-брейка. Карточка сохраняет своё место; флажок не переключает видимость слова. На скрытой карточке панель не раскрывает текст. После завершения партии у строк истории есть отдельные кнопки; «Блиц» предоставляет кнопку для каждого исходного слова, тай-брейк — свою кнопку.

Панель поддерживает шесть причин. При любой причине доступен необязательный комментарий до 160 Unicode-символов, пробелы нормализуются, вывод экранирован. Back, Escape, фон и Отмена закрывают панель без записи жалобы. Клавиатурный фокус удерживается в диалоге и возвращается к вызвавшей кнопке. Issue #96 заменяет прежнюю политику непрерывного отсчёта: открытие жалобы фиксирует оставшееся время в current.feedbackHold и надёжно сохраняет его до показа диалога. Закрытие возобновляет только ранее работающий таймер; исходная пауза сохраняется. Перезапуск открывает ту же жалобу при Continue. Просроченный до нажатия раунд не оживает. Подробности — CARD-FEEDBACK.md.

## Идентификация без изменения выбора

`pullWord` принимает необязательный объект-приёмник ID. В ветке task-history в него копируется `selected.record.id` именно из уже выбранной записи. Функция по-прежнему возвращает прежний текст; порядок пула, RNG, выбор модификатора и баланс не меняются. `rollOutcome` сохраняет `cardId` и параллельный массив `blitzCardIds`. Замена слова обновляет ID; пропуски/отгаданные слова «Блица» используют существующую очередь индексов и соответствующий ID. История завершённого раунда сохраняет эти метаданные для последующей отметки.

Числовые задания используют `question.id`, специальный решающий вопрос — `game.tiebreak.question.id` и context=tiebreak. Старые текущие слова и история без исходного ID получают `cardId:null`; поиск по одинаковому тексту не применяется. Старый «Блиц» без отдельного массива может быть описан только общим текстом из истории, ID при этом отсутствует. При отсутствии старой сложности/набора эти поля честно равны null.

## Хранилище и экспорт

Независимый ключ `kvip-card-reports:v1`, формат `{version:1,items:[...]}`. Запись содержит только itemKey, снимок `{cardId,pack:{id,version}|null,context,modeId,methodId,difficulty,text}`, reason, comment, createdAt/updatedAt. Строгая валидация списка допустимых полей не позволяет сохранять дополнительные профили, имена игроков, счёт, ID матча или всю историю. Произвольный комментарий является текстом самого пользователя.

Для известного ID itemKey учитывает источник/версию набора и устойчивый ID: то же задание в другом режиме не создаёт лишнюю запись. Для неизвестного ID используется контекст/режим/способ/сложность и текст; он не объявляется восстановленным ID. Повтор той же карточки предлагает **Изменить замечание**; отдельное согласие не даёт молча перезаписать предыдущую причину. Устаревшее редактирование/удаление/очистка отклоняется.

Максимум 500 записей. При достижении лимита новые записи запрещены с пояснением; редактирование существующих доступно, старые данные не удаляются. Повреждённая/неизвестная версия сохраняется без перезаписи. Запись подтверждается чтением; ошибка вызывает проверенный rollback. Неподтверждённый rollback блокирует последующие записи журнала в текущем процессе. Игровые ключи и профильная статистика не изменяются операциями с замечаниями.

Настройки → **Замечания к заданиям**: счётчик, просмотр/редактирование, удаление одной записи, экспорт `kvip-card-reports-YYYY-MM-DD.json`. Очистка всего журнала требует явного подтверждения и проверки исходного RAW. Экспорт — JSON `{kind,version,exportedAt,archive}`; файл не содержит резервную копию статистики и не отправляется на сервер. Импорт замечаний в приложении не добавляется; сохранённый локальный журнал читается после перезапуска.

## Модули, PWA и проверки

`card-reports.js` — снимки, схема, dedupe, запись/экспорт; `card-reports-view.js` — флажок, диалог и журнал. В app.js регистрация UI и узкое исключение для стандартного редактирования комментария. Ветки TASK 016 и TASK 017 независимы, словари и PR #85 не меняются.

PWA v77 содержит оба модуля в precache, версии изменённых runtime-файлов синхронны в HTML и SW. Архитектор при совместной интеграции должен объединить подключения и precache с TASK 016; эта ветка от main v75 не включает её UI.

Unit-проверки: все 8 режимов/Секретка/Блиц; точное сравнение с исходным round-selection.js на фиксированных seed, включая количество RNG и состояния планировщиков; старые ID=null; tie; dedupe/редактирование; Unicode-лимит; 500 записей; quota/readback/rollback; stale операции; перезапуск/экспорт и отсутствие изменений игры/профилей. Browser: 320×568, 390×844, 844×390, touch/клавиатура/Back/Escape, скрытое слово/таймер, Блиц/Примерно/tie, offline reload/download/list/delete/clear. Геометрия и карточка дополнительно проверяются существующими suites. Эмуляция Chromium не является проверкой физического Android.
